# 商户数据梳理

本清点针对 2026-11-10 本地 `hmdianping` 数据库，数量是当时快照，不代表线上实时数据。商户、优惠券及帖子保留原有主键，未自动合并或删除。

## 数据概况

- `tb_shop` 共 77 条：63 条标记为沈药周边公开 POI，另有 14 条历史演示商户；所有记录均有坐标值，不代表坐标准确。
- 14 条商户记录有图片地址，均为历史演示商户；63 条公开 POI 没有商户图片。页面使用的菜品照片是分类示意，不可认定为商户实拍。
- `tb_voucher` 共 4 条、关联 3 家商户；`tb_voucher_order` 共 5 条。
- `tb_blog` 中 7 条带正数 `shop_id`，关联 4 家商户；另有 22 条 `shop_id` 为 0 或空。帖子主题与店铺的真实对应关系尚未逐条验证。
- 商户类别数量：类型 1 为 29，类型 2 为 10，类型 3、4、5、6、7、8、10 各 5，类型 9 为 3。

## 坐标和来源

公开 POI 来源和原始 GCJ-02 坐标见 `scripts/import_shenyang_public_poi.sql` 与 `frontend-vue3/src/data/category-pois.json`。导入脚本将坐标近似转换为 WGS-84 后写入 `tb_shop.x/y` 和 Redis GEO；来源页面及当前营业状态尚需核实。

历史商户 ID 1–14 的坐标由 `scripts/relocate_geo.py` 按距离和方位模拟生成，脚本明确说明这些坐标不代表实际位置。旧记录部分仍保留杭州地址和图片，不能作为真实沈阳商户或用于实地导航。

坐标约定：社区商户数据库与 Redis GEO 使用 WGS-84；`shop_amap_link` 的经纬度保留高德 GCJ-02，并标注坐标系。高德附近搜索在服务端将 WGS-84 转为 GCJ-02，地图中心在浏览器侧转换。原始记录不因建立关联而覆盖；校园中心点仍是近似位置。

## 高德关联

福锅记原商户 ID 18、地址“大南街438号”。高德 POI 详情查询到 `B00180JT2W`，名称“福锅记(大南店)”，地址同为沈阳市沈河区大南街 438 号；高德坐标 `123.455329,41.774465`（GCJ-02）。依据名称和地址建立一条 `shop_amap_link` 记录，原商户、演示优惠券和订单未更改。营业状态和店名变化仍需实地或商户确认。

其余历史商户存在名称、地址或模拟坐标冲突，未自动绑定。63 家公开 POI 已逐条发起高德候选查询，均返回至少一个候选。简单名称和地址文本比对得到 13 条候选吻合，仅供人工复核，不能视为已确认匹配；完整候选结果保存在本机 `target/amap-shop-candidates.json`。历史模拟商户仍需单独确认。

`shop_amap_link.sql` 只创建关联表，不含线上 POI 绑定数据；关联应逐条核实后写入。`GET /map/shop/{id}` 可查询已绑定记录，无绑定时返回空数据。
